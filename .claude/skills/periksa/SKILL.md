---
name: periksa
description: Review akhir hasil tugas kuliah sebelum dikumpulkan menggunakan subagent pemeriksa.
argument-hint: "[folder-tugas]"
---

Panggil subagent `pemeriksa` untuk folder tugas: $ARGUMENTS (jika kosong, pakai folder di `tugas/` yang paling baru diubah).

Tampilkan laporannya ke pengguna apa adanya, lalu tawarkan untuk memperbaiki temuan yang ada. Jangan mengubah file sebelum pengguna setuju.
